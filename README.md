# Halifax Digital Twin Sionna Bundle

This repository is a paper-sharing bundle for the Halifax peninsula digital twin used with Sionna RT. It contains the generated 3D scene, the minimal input data needed by the notebooks, and two runnable tutorial notebooks.

The preprocessing pipeline, raw DEM/DSM/OSM/NSTDB inputs, intermediate caches, simulation databases, and report artifacts are intentionally not included.

## Scene Variants

The bundle includes two Sionna-ready XML scene files:

- `scene/halifax_peninsula_multi_material.xml`: terrain plus material-separated building meshes using brick, concrete, metal, and wood/asphalt material assignments.
- `scene/halifax_peninsula_mono_concrete.xml`: the same geometry, with every building mesh loaded as concrete. The terrain remains ground material.

Both XML files reference the shared PLY files in `meshes/` using relative paths.

## Data Files

- `data/peninsula_cellular_antennas_2g_to_5g.csv`: filtered cellular antenna records used by the notebooks.
- `data/building_heights_selected.gpkg`: processed Halifax peninsula building footprints and selected heights.
- `outputs/`: output directory for figures and maps generated by the notebooks.

## Setup

Create a Python environment and install the dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m ipykernel install --user --name halifax-twin --display-name "Halifax Twin"
```

Launch JupyterLab:

```bash
python -m jupyter lab
```

Open one of the notebooks in `tutorials/` and select the `Halifax Twin` kernel.

## Notebook Inputs

The notebooks discover the project root by walking upward until they find `data/`. Keep the top-level folder layout unchanged.

Required inputs:

```text
scene/halifax_peninsula_multi_material.xml
scene/halifax_peninsula_mono_concrete.xml
scene/terrain_metadata.txt
meshes/*.ply
data/peninsula_cellular_antennas_2g_to_5g.csv
data/building_heights_selected.gpkg
```

Notebook outputs are written to:

```text
outputs/
```

The committed notebooks are executed in CPU-preview mode so they render on a laptop and display correctly on GitHub. For higher-resolution publication runs, increase the radio-map cell resolution and ray/sample counts in the notebook setup cells before re-running.

## Switching Scene Material Model

The notebooks load the multi-material scene by default:

```python
SCENE_XML = str(SCENE_XML_MULTI)
```

To use the mono-concrete scene, change that line in the setup cell to:

```python
SCENE_XML = str(SCENE_XML_MONO_CONCRETE)
```
